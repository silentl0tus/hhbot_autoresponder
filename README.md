# 🤖 HH Autoresponder Bot

Это Telegram-бот для автоматических откликов на вакансии hh.ru с опциональной поддержкой ИИ (Claude / Gemini / etc) для прохождения опросов и тестов работодателей.

Основной код и более подробная документация лежат в папке `hh-autoresponder`. 
В корневой папке лежат удобные скрипты для быстрого старта на любой ОС.

---

> [!WARNING]
> **Важное требование: VPN / Proxy**
> Для корректной работы бота (особенно из РФ) требуется, чтобы на вашем компьютере или сервере был включен общесистемный **VPN** или настроен **Proxy**. 
> Это необходимо, так как:
> 1. API Telegram часто блокируется локальными провайдерами.
> 2. Провайдеры нейросетей (OpenAI, Anthropic Claude, Google Gemini) ограничивают доступ по геолокации. Без VPN бот не сможет генерировать сопроводительные письма и проходить анкеты.

## 🚀 Быстрый старт (Установка и запуск)

Для работы бота вам понадобится установленный **Python 3.12+**. 

### 1. Настройка
1. Перейдите в папку `hh-autoresponder`.
2. Скопируйте файл `.env.example` и переименуйте его в `.env`.
3. Откройте `.env` и впишите туда ваш токен бота Telegram, ваш ID, логин и пароль от hh.ru.

### 2. Запуск на Windows 🪟
Вам не нужно писать команды в терминале, всё автоматизировано:
- Для первого входа в аккаунт hh.ru запустите **`login_windows.bat`**. Откроется браузер — авторизуйтесь руками (сессия сохранится).
- Для обычного запуска бота просто двойным кликом запустите **`run_windows.bat`**.

### 3. Запуск на Linux / macOS 🐧
В корне проекта есть скрипты для автоматической установки:
```bash
# Выдаем права на выполнение скриптов
chmod +x run_linux.sh login_linux.sh

# Шаг 1: Авторизация на hh.ru (один раз)
./login_linux.sh

# Шаг 2: Запуск бота
./run_linux.sh
```

## 🛠 Устранение неполадок (Troubleshooting)

- **Ошибка: Unknown scheme for proxy URL URL('socks://...')**
  Если у вас настроен глобальный SOCKS-прокси в системе, скрипты запуска для Linux автоматически исправят его на правильный формат `socks5://`.
- **Ошибка: Host validation warning при установке Playwright (Linux)**
  Если при установке браузера система жалуется на отсутствие библиотек, выполните команду для установки системных зависимостей:
  `cd hh-autoresponder && source .venv/bin/activate && sudo playwright install-deps`
