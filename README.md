# hh-autoresponder — бот автооткликов на вакансии hh.ru (хх ру)

**Автоотклики на hh.ru на автопилоте.** Телеграм-бот сам ищет вакансии на
**hh.ru** по вашим запросам, отбирает подходящие и **автоматически откликается**
за вас — ровным, человеческим темпом. Бесплатный, с открытым кодом
(open-source), запускается на вашем компьютере или сервере. Всё управление и подробный лог —
в Telegram.

Проще говоря: вы настраиваете **автоотклик на вакансии hh** один раз — и бот сам
рассылает отклики, пока вы занимаетесь своими делами.

> ⚠️ **Дисклеймер.** Автоматические отклики на вакансии нарушают правила hh.ru —
> аккаунт могут ограничить. Держи разумные лимиты и используй на свой риск.
> Проект — для личного использования.

---

> [!WARNING]
> **Важное требование: VPN / Proxy**
> Для корректной работы бота (особенно из РФ) требуется, чтобы на вашем компьютере или сервере был включен общесистемный **VPN** или настроен **Proxy**. 
> Это необходимо, так как:
> 1. API Telegram часто блокируется локальными провайдерами.
> 2. Провайдеры нейросетей (OpenAI, Anthropic Claude, Google Gemini) ограничивают доступ по геолокации. Без VPN бот не сможет генерировать сопроводительные письма и проходить анкеты.
> 
> 🔴 **Критичный нюанс:** При включенном VPN ваш трафик к сайту **hh.ru должен идти напрямую (в обход VPN)**. HeadHunter активно блокирует зарубежные IP-адреса и публичные VPN, поэтому вход в аккаунт и отклики будут работать только с российского IP. Настройте раздельное туннелирование (split tunneling) в вашем VPN-клиенте.

## 🌟 Особенности и Возможности

- **Мультиплатформенность:** Бот работает одновременно с hh.ru и Хабр Карьерой!
- **Аналитика от ИИ:** Бот не просто шлёт отклики вслепую. Каждая вакансия оценивается нейросетью (GPT-4 / Claude / LLaMA / DeepSeek / Gemini) от 0 до 100 баллов на соответствие вашим навыкам и ожиданиям.
- **Умное сопроводительное письмо:** Нейросеть генерирует уникальное, осмысленное письмо под каждую вакансию, аргументируя, почему вы подходите.
- **Гуманизатор текста (Анти-AI):** Убирает "роботизированный" тон из сопроводительных писем, делает их более естественными и сухими, чтобы рекрутеры не поняли, что писал ИИ.
- **Обход алгоритмов hh.ru:** Использование динамических лимитов откликов на каждый день и случайных задержек между действиями, чтобы антифрод-система не заблокировала аккаунт.
- **Тихие часы:** Бот не беспокоит вас уведомлениями ночью (настраивается).
- **Telegram Интерфейс:** Управление настройками, лимитами, ИИ-моделями и статистика — всё прямо в Telegram-боте.
- ⬆️ **Автоподнятие**: Автоматически поднимает резюме в поиске hh каждые 4 часа.

### Кнопки управления в Telegram
- 🟢/⏸ **Автоотклик**: Включение и выключение автоматического поиска и рассылки откликов.
- 📊 **Статистика**: Показывает воронку откликов (отправлено, отказы, приглашения, нет ответа).
- ⚙️ **Настройка функций**: Включение/выключение ИИ-генерации писем, гуманизатора, ответов на тесты и автоподнятия резюме.

## Требования

- **Python 3.12+**
- Аккаунт на **hh.ru** с опубликованным резюме
- Телеграм-бот (токен из [@BotFather](https://t.me/BotFather))
- (опционально) ключ LLM-провайдера (любого совместимого с OpenAI API), если нужно генерировать письма, проходить тесты и использовать гуманизатор.
- Настроенный VPN (см. предупреждение выше).

База — SQLite (файл). Ни Postgres, ни Redis, ни Docker ставить не нужно.

## 🚀 Быстрый старт (Установка и запуск)

Этот репозиторий представляет собой удобную обертку для локального запуска на Windows и Linux.

### 1. Настройка
1. Скопируйте файл `hh-autoresponder/.env.example` и переименуйте его в `hh-autoresponder/.env`.
2. Откройте `.env` и впишите туда ваш токен бота Telegram, ваш числовой ID Telegram, логин и пароль от hh.ru.
3. Отредактируйте параметры отбора (запросы, ключевые слова, зарплаты).
4. **Важно:** Создайте файл `hh-autoresponder/data/resume.txt` (если его нет) и вставьте туда полный текст вашего резюме. Бот будет использовать этот текст как контекст для нейросети при написании уникальных сопроводительных писем!

### 2. Запуск на Windows 🪟
Вам не нужно писать команды в терминале, всё автоматизировано:
- Для первого входа в аккаунт hh.ru запустите **`login_windows.bat`**. Откроется браузер — авторизуйтесь руками (сессия сохранится).
- Для обычного запуска бота просто двойным кликом запустите **`run_windows.bat`**.

### 3. Запуск на Linux / macOS 🐧
В корне проекта есть скрипты для автоматической установки:
```bash
# Выдаем права на выполнение скриптов
chmod +x run_linux.sh login_linux.sh

# Шаг 1: Авторизация на hh.ru (один раз)
./login_linux.sh

# Шаг 2: Запуск бота
./run_linux.sh
```

## 🛠 Устранение неполадок (Troubleshooting)

- **Ошибка: Unknown scheme for proxy URL URL('socks://...')**
  Если у вас настроен глобальный SOCKS-прокси в системе, скрипты запуска для Linux автоматически исправят его на правильный формат `socks5://`.
- **Ошибка: Host validation warning при установке Playwright (Linux)**
  Если при установке браузера система жалуется на отсутствие библиотек, выполните команду для установки системных зависимостей:
  `cd hh-autoresponder && source .venv/bin/activate && sudo playwright install-deps`

## 📝 Список изменений (Changelog)

- **Динамические дневные лимиты**: Теперь бот каждый день автоматически генерирует случайный лимит откликов на день в пределах заданного диапазона (MIN и MAX) для лучшего обхода алгоритмов hh.ru.
- **Интеграция Гуманизатора (Анти-ИИ)**: Внедрен алгоритм очистки текста от ИИ-штампов и канцеляризмов (интеграция правил `digitaltraffic-detectai`). Включается прямо из интерфейса Telegram-бота.
- **Повышена стабильность API**: Добавлена грациозная обработка ошибок (например, `503 Service Unavailable`) от провайдеров LLM, чтобы бот не падал при временной недоступности серверов.
